# The Creative Testing System

Creative is the highest-leverage variable in paid media. Targeting is largely automated now; the message is not.

## The 3×3×3 cadence
Every testing round ships **3 angles × 3 hooks × 3 formats**. Never test one ad against one ad — you'll wait weeks for significance that never arrives.

- **Angles** — the reason to care (see `offer-and-messaging.md`)
- **Hooks** — the first 3 seconds / first line
- **Formats** — UGC talking head, static with text, demo, before/after, founder-to-camera, testimonial

## Testing rules
1. **One variable per comparison.** If you change the hook and the offer, you've learned nothing.
2. **Give it enough budget.** Minimum ~50 conversions per variant before calling a winner, or 3–5× target CPA in spend before killing one.
3. **Kill on a rule, not a feeling.** e.g. "cut at 3× target CPA with zero conversions."
4. **Winners get scaled, not retired.** Then iterate on the winner: same angle, new hook.
5. **Refresh on a schedule.** When frequency exceeds ~2.5–3.0 in a 7-day window, or CTR drops 30% from its peak, fatigue has arrived. Plan for it instead of reacting to it.

## The creative brief (one per concept)
- Angle and the customer belief it targets
- Hook — the exact first line or first frame
- Body — the three points in order
- Proof element
- Call to action
- Format, aspect ratio, duration
- What we expect to learn if it wins *and* if it loses

## Client-side creative supply
Ask for, at onboarding: product footage, workspace/team footage, customer testimonials on video, before/afters, founder-to-camera clips. The single best predictor of long-term account performance is how much raw material the client can supply. Build a recurring monthly ask into the relationship.

## Creative library
Keep every ad ever run with: spend, CPA, CTR, hook rate, and a one-line note on why we think it did what it did. This library is the real asset — it's what makes month 6 cheaper than month 1.
