# Template 06 — Internal 14-Day Onboarding Checklist

## Day 0 — Contract signed
- [ ] Countersigned agreement filed
- [ ] Deposit / first invoice issued and confirmed
- [ ] Client record created in CRM; deal moved to Onboarding
- [ ] Project folder + shared drive created: `RELIER × {{CLIENT}}`
- [ ] Slack channel created and client invited
- [ ] Team assigned: account lead, strategist, media buyer, creative
- [ ] Welcome email sent (Template 01) with intake form, access checklist, kickoff booking link

## Days 1–2 — Setup
- [ ] Kickoff call booked and calendar invite accepted
- [ ] Access requests sent for every platform (Template 03)
- [ ] Internal kickoff (30 min) — team briefed on the deal, promises made in the sale, red flags
- [ ] Read the sales call recording/notes; note every promise made so delivery matches the pitch

## Days 2–5 — Discovery
- [ ] Intake form returned and scored
- [ ] All access granted and verified (log in to each, don't assume)
- [ ] Analytics audit: is tracking accurate? Any of it trustworthy?
- [ ] Ad account audit: historical spend, CPA, what's already been tested
- [ ] Website/landing page audit: speed, mobile, forms, friction
- [ ] Competitor scan: 5 competitors, their ads (Meta Ad Library / Google Ads Transparency), offers, landing pages
- [ ] Customer language mining: reviews, support tickets, sales call transcripts → swipe file
- [ ] Kickoff call held; recap sent within 24 hours

## Days 6–10 — Strategy
- [ ] Funnel map drafted (see `frameworks/sales-funnel-blueprint.md`)
- [ ] Offer and messaging defined (see `frameworks/offer-and-messaging.md`)
- [ ] 90-day roadmap built with named milestones
- [ ] Budget allocation and forecast modelled (target CPA, expected volume, breakeven)
- [ ] Strategy presented to client; approval or redlines captured in writing

## Days 11–14 — Build & launch
- [ ] Tracking implemented: GA4, GTM, pixels, conversions API/server-side, call tracking, UTM convention documented
- [ ] Conversion events tested end-to-end with a real test submission
- [ ] Landing page(s) built and QA'd on mobile
- [ ] CRM/lead routing connected and tested; client confirms they received the test lead
- [ ] First creative batch produced and approved (minimum 3 concepts × 3 variants)
- [ ] Campaign structure built; budgets, schedules, and caps set
- [ ] Pre-launch QA checklist signed off by a second person
- [ ] **Launch.** Confirm in writing with the client the moment spend starts.
- [ ] Reporting dashboard live and shared

## Day 15+ — Operate
- [ ] Weekly written update scheduled as a recurring task
- [ ] Monthly strategy call recurring in both calendars
- [ ] Day 30 review booked
- [ ] Day 60 testimonial/case-study ask diarised

## Pre-launch QA (second pair of eyes required)
- [ ] Correct ad account, correct payment method, correct currency
- [ ] Daily and lifetime budget caps sane — check for the extra zero
- [ ] Geo, language, age, and exclusion targeting correct
- [ ] Existing customers excluded where relevant
- [ ] Every link works, has UTMs, and lands on the right page
- [ ] Conversion event fires and is attributed
- [ ] Ad copy proofread; claims compliant
- [ ] Landing page loads under 3s on mobile
- [ ] Form submits and the lead lands in the client's inbox/CRM
